Cleon Guide delivers interactive, in-app walk-throughs, tooltips, and HR process guides that help users — from new employees to experienced HR managers — complete tasks correctly and confidently without leaving the platform to search for instructions.

HR Administrators

Key Features

Interactive Step-by-Step Tours

Guided, dynamic workflows that highlight UI elements, explain actions, and confirm successful completion of each step.

Contextual Tooltips & Hints

On-demand information hints that appear when users hover over fields to contextualize complex decisions.

HR Process Library

Curated library of HR process guides covering performance reviews, payroll onboarding, expense submissions, and more.

Custom Guide Builder
